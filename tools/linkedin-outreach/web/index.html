Import your LinkedIn connections

  1. On LinkedIn: Settings → Data privacy → Get a copy of your data, tick Connections, request the archive.
  2. LinkedIn emails you a download link (usually within about 10 minutes). Unzip it to find Connections.csv.
  3. Choose that file below. You can import again any time to refresh.

Choose who to message

Separate several values with commas; any one of them matching counts. These filters decide who gets the campaign you write next.

Write the message

{company|work} means "use the company, or work if it's blank". People messaged in any campaign in the last 30 days are skipped.

Review and edit drafts

Edit any message before it's sent. "Skip" leaves someone out of this campaign; "Never contact" leaves them out of all campaigns.

Step 1 - Log in to LinkedIn (once)

Opens a separate browser window. Log in there yourself; this tool never sees your password. The login is remembered on this computer.

Step 2 - Send automatically

Automated messaging is against LinkedIn's User Agreement and can get an account restricted. The defaults are cautious; sending stops by itself if LinkedIn shows a security check or warning.
